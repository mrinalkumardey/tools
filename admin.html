🔑 Create New User

Add users to BU Tool Dashboard

⚠️ Important Note: Due to Firebase limitations with client-side user creation, you'll need to manually create user accounts in the Firebase Console. This page will guide you through the process.

📝 How to Create Users:

  1. Go to Firebase Console
  2. Select your project: bu-tools-dashboard
  3. Navigate to Authentication → Users tab
  4. Click "Add user" button
  5. Enter the user's email and password (min 6 characters)
  6. Click "Add user"
  7. Share the credentials with the user securely

💡 Tip: Save this page as a bookmark for quick access to user creation instructions!
