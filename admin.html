👥 Create New Users

Instructions for adding users to the dashboard

📝 How to Create Users:

  1. Go to Firebase Console
  2. Select your project: bu-tools-dashboard
  3. Navigate to Authentication → Users tab
  4. Click the "Add user" button
  5. Enter the user's email and password (min 6 characters)
  6. Click "Add user"
  7. Share the credentials with the user securely

💡 Pro Tip: After creating users, you can monitor their activity in the Admin Panel to see which tools they're using and when!
